# ③ 错误可重试（kill -9 真实失败注入 → 重启 → 点重试恢复）✅

## 真实注入链

1. `kill -9 <后端PID>`（进程级真失败，非 route abort）
2. 开详情抽屉（列表有缓存，**详情查询无缓存 ⇒ 必错**）
3. `restart-server.sh` 真实重启（kill 残留 + 清应用级写锁 + 等就绪）
4. 点「重试」⇒ 数据恢复

## 结构性发现（登记）

全页错误分支（`任务中心加载失败`）要求 `isError && !data`；SPA 与 API **同源伺服**
（FMBY_WEB_ROOT）⇒ 后端死 = SPA 首载也死 ⇒ 全页错误态在真栈同源形态下**结构性不可达**；
真实可达错误面 = 详情抽屉（detailQuery.isError）。这是产品事实，不是测试缺陷。
