# 规则（照后端 scripts/lib/node-gates-known-red.txt 范式）：
#   · 登记项必须是**已开 issue 的存量失败**，不得登记「暂时不想修」；
#   · 条目修绿后必须**删除本行**；若未删 ⇒ STALE 反噬判红（台账不是永久豁免）；
#   · 门禁当前只做「提示 + 引导登记」，不把台账当 allowlist 静默放行
#     （静默放行 = 把 known-red 变成 skip，与「诚实化」裁定相悖）。
